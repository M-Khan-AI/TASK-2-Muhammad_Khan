## Project Title

Expense Tracker

## Project Description

A simple Python program that allows users to enter multiple expenses and calculates the total amount spent.

## Features

- Enter multiple expenses
- Automatically calculate the total spent
- Type `done` to finish entering expenses
- Simple command-line interface
- Uses basic Python programming concepts

## Technologies Used

- Python 3
- VS Code

## How to Run

1. Clone the repository

git clone <your-github-repository-url>

2. Open the project folder

## How to Use

Enter your expenses one by one.

Example:

Enter expense (or type 'done' to finish): 100
Enter expense (or type 'done' to finish): 50
Enter expense (or type 'done' to finish): 20
Enter expense (or type 'done' to finish): done

Total Spent: 170.0

The program adds the expenses:

100 + 50 + 20 = 170
